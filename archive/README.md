# Archive

Archived content is retained for provenance and rollback, not used by active
workflows.

- `legacy_pipeline/`: superseded code and historical control files
- `retired_experiments/`: non-promoted model or analysis iterations
- `historical_reports/`: superseded rendered reports

Every move into this tree must be recorded in a plan and result map under
`maintenance/reorganization/`. Large scientific files are not duplicated
merely for archiving; their manifests and checksums are retained.
