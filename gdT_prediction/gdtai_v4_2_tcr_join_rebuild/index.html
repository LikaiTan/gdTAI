Rebuild method

1. Parse raw VDJRequire cell-associated, high-confidence, productive contigs with nonempty CDR3.
2. Select within chainHighest UMI, then reads, full-length status, then stable contig id.
3. Join safelyCanonical sample id plus nucleotide barcode core. Barcode-only fallback is forbidden.
4. Fail closedDuplicate RNA keys, collapsed raw libraries, or poor source recovery cannot provide TCR truth.
The 50% source floor only detects structural mapping failure; passing sources recover 93.2%-100.0% of eligible raw keys.
GSE235863 is an author receptor table without UMI/read columns. These are null, not zero. Across UMI-auditable calls, 72,049 selected chains have UMI=1.

The four-chain sidecar contains CDR3 amino acid/nucleotide sequence, V/D/J calls, clone id, UMI, reads, support-availability flags, selected contig id, productive-contig multiplicity, and raw source-file provenance.
