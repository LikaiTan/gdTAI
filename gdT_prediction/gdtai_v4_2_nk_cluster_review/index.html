9. Recommended decision

Strict core recommendation: retain 461 cells. These cells pass both independent cell-level evidences and fall in cluster 19, which contains 96.1% of all primary NK anchors. Hold the remaining 8 current calls outside cluster 19 rather than using them as strict training NK labels.

No automatic expansion is recommended yet. Cluster 19 contains plausible dropout-rescue tiers, but its eligible candidates are 86.7% from one source, above the 70% source cap. Cluster 9 is a biologically plausible secondary NK-like cluster with better source balance, but it has only 48 primary NK anchors and weak latent-anchor passage. Both require source-resolved review before use.

Decision boundary

No H5AD or frozen label manifest is changed by this report. A defensible expansion should require coherent NK-lineage expression, low T-lineage and myeloid support, localization to reproducible unsupervised clusters, and acceptable source composition. Cytotoxicity alone, one receptor, or the historical scANVI label alone is insufficient.
